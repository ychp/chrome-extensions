## 窗口数量统计&窗口排序 tab-sorter
浏览器标签增强：一键排序当前窗口的所有标签，并在扩展图标上显示全局标签数量。

### 功能
- **排序模式**（在扩展“选项”页可切换，默认字典升序）：
  - 字典升序（Dictionary Asc）
  - 字典降序（Dictionary Desc）
  - 最近使用优先（LUR：Last Used Recent，按 lastAccessed 降序）
- **移动位置**：排序后会按结果顺序重排标签位置
- **标签总数**：自动统计并在图标上显示当前所有窗口标签数

### 使用
1. 点击扩展图标，即可按当前模式对“当前窗口”的所有标签排序并重排位置
2. 在右键菜单或扩展“选项”页选择排序模式


## 时间戳转换 time-convertor
选中文本自动识别 10 位/13 位时间戳，弹窗展示本地时间、UTC 与相对时间，并支持一键复制。

### 使用
1. 在任意网页选中时间戳（例如 `1700000000` 或 `1700000000000`）
2. 看到带有转换结果的弹窗
3. 页面控制台会输出带前缀的日志：`[TimeConvertor] ...`
