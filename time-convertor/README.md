# Time Convertor Chrome Extension

一个简单易用的Chrome浏览器插件，可以自动识别页面中选中的时间戳文本，并将其转换为可读的时间格式。

## 功能特性

- 🔍 **自动检测**: 选中文本时自动检测是否为时间戳
- ⏰ **多格式支持**: 支持秒级和毫秒级时间戳
- 🌍 **多时区显示**: 同时显示本地时间和UTC时间
- 📋 **一键复制**: 快速复制转换后的时间文本
- 🎨 **美观界面**: 现代化的弹窗设计，支持暗色主题
- ⚡ **轻量高效**: 无需额外配置，即装即用
 - 🪵 **调试友好**: 关键行为在页面控制台以 `[TimeConvertor]` 前缀输出

## 安装方法

1. 下载或克隆此项目到本地
2. 打开Chrome浏览器，进入 `chrome://extensions/`
3. 开启右上角的"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择项目文件夹 `time-convertor`
6. 若需在 `file://` 页面生效，请在扩展详情页启用“允许访问文件网址”
7. 插件安装完成！

## 使用方法

1. 在任意网页上选中包含时间戳的文本
2. 插件会自动检测并显示转换结果弹窗
3. 弹窗中会显示：
   - 原始文本
   - 时间戳数值和单位
   - 本地时间
   - UTC时间
   - 相对时间（如"2小时前"）
4. 点击"复制"按钮可以快速复制时间文本

## 支持的时间戳格式

- **秒级时间戳**: 10位数字，如 `1640995200`
- **毫秒级时间戳**: 13位数字，如 `1640995200000`
- **混合文本**: 包含时间戳的文本，如 `timestamp: 1640995200`

## 技术实现

- **Manifest V3**: 使用最新的Chrome扩展API
- **Content Script**: 监听页面文本选择事件
- **Background Script**: 处理插件状态和消息通信
- **响应式设计**: 适配不同屏幕尺寸
- **无障碍支持**: 支持键盘操作和屏幕阅读器

## 调试与排障

在页面控制台查看日志（有 `[TimeConvertor]` 前缀）：

- 选中文本但无弹窗：
  - 确认控制台是否打印 `selected_text` 与 `timestamp_detected`
  - 页面类型限制：扩展无法在 `chrome://*`、Chrome 应用商店页面运行
  - 如在本地 `file://` 页面，需启用“允许访问文件网址”
  - 确认选中的是否为 10 位（秒）或 13 位（毫秒）时间戳
  - 尝试在普通 `https://` 页面测试
